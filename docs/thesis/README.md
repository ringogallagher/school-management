# Thesis sources

`main.pdf` is the compiled thesis. Build: `latexmk -pdf main.tex` (needs a TeX Live with tikz, listings, booktabs, mathptmx).
Placeholders in red (supervisor, candidate, study programme) and the AI-use declaration at the end must be completed by the candidate.
`fig/` holds screenshots taken from the demo school (`go run ./cmd/seed`) and the load-test chart (data in docs/testing.md).
